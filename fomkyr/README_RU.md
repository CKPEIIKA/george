# Fomkyr 0.7.1

Fomkyr — точный C-движок для однородных некоммутативных базисов Грёбнера.
Полная документация: [README](README.md).

Версия 0.7.1 добавляет общий план критических перекрытий текущей степени.
`--pair-order overlap` сначала выбирает длинные перекрытия, затем меньшие входные
многочлены. `--pair-order sparse` сначала выбирает меньшие входы.
По умолчанию сохраняется прежний порядок `legacy`. План начинает работать
со степени 12, его общий лимит — 64 МиБ. Пример FK6 в George выбирает `overlap`.

Частичные задания с активным планом используют frontier v2 и требуют читателя
0.7.1. Перед обновлением сохраните копию задания. При переходе с прежнего порядка
уже зафиксированная работа сохраняется. Подробнее:
[планирование и продолжение](docs/PAIR_PLANNING_071.md).

Профиль размерностей FK включается отдельно; результаты с ним явно условны
относительно импортированных размерностей. Сохраняются рабочие области больших
строк, вспомогательные редукции, телеметрия и секундная терминальная панель
`./fomkyr-dashboard.sh /path/to/job`.
