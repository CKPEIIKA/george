# FK6 dimension profile

Imported total and product-permutation dimensions over Q through degree 20, plus
C counting adapters for Fomkyr. Runtime use requires explicit acceptance of the
imported authority. See [the mathematical and persistence contract](../docs/FK_GATE.md).

The external computational proof package is not embedded or replayed here.
Artifact digests and public provenance are in `profiles/proof-provenance.json`;
external specialist review remains pending. No dimensions above 20 are extrapolated.

Fomkyr 0.7.5 also accepts explicitly supplied, identity-bound sector policies
for presentations with labelled S6 transpositions. See
[star inputs and policy format](../docs/RELEASE_075.md).
