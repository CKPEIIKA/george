# FK6 dimension profile

Fixed total and product-permutation dimensions over Q through degree 17, plus
C counting adapters for Fomkyr. Runtime use requires explicit acceptance of the
imported authority. See [the mathematical and persistence contract](../docs/FK_GATE.md).

The external computational proof package is not embedded or replayed here.
Artifact digests and public provenance are in `profiles/proof-provenance.json`;
external specialist review remains pending. No dimensions above 17 are extrapolated.

unpublished development references are excluded from this source bundle.
