# Source provenance

Mathematical table values and the core FK counting code come from the imported
FK Gate 0.3 distribution. Private artifact names are omitted from public
provenance; original artifact digests and the upstream provenance checksum are
retained. Both profile identities denote the same mathematical tables and are
accepted only with explicit opt-in on resume. See [the contract](../docs/FK_GATE.md).

Current engine hooks are in `adapters/sector_counter.inc` and `../src/fk_gate.inc`.
Reference installers target earlier engine layouts. Reports and unpublished
proof artifacts remain outside the distributed source tree.
