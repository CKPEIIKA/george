# Optional certified degree gate

The subsystem consumes the authenticated FK6 profile over Q through degree 17.
Other inputs, fields and higher degrees use ordinary exact completion.

The integration binds the presentation and field, counts total and permutation
components at degree start or restore, observes only distinct newly committed
leaders, skips closed components under the imported dimension assumption, and
requires a fresh scalar recount before closing a whole degree.

Counter resource exhaustion disables the optional shortcut. Invalid state,
corrupt input and inconsistent counts remain errors. Shared counts change only
at joined worker barriers. The proof archive is represented by its digest; the
runtime does not replay it.

This branch already implements the five hooks. The retained reference installer
is for its specified older layout; use source integration for other versions.
